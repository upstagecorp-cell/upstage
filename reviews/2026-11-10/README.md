최신 유료 출시 검토: [7일 출시 판단·플랜·세금·수령액](../../SEVEN_DAY_LAUNCH_PLAN.md). 구독 구현과 세금 가정을 구체화한 후속 기록이며, 순이익 목표 계산에는 [출시 모형](launch/unit-economics.html)을 우선한다. [운영 연결 절차](launch/OPERATIONS_RUNBOOK.md) · [검증 결과·실제 화면](launch/VERIFICATION.md).

후속 실제 구현: [시각 경험·반복 사용 기능 적용 결과](../../VISUAL_EXPERIENCE_IMPLEMENTATION.md). 아래 문서들은 구현 전 검토 기록이며, 승인본 재사용·체크 이어하기·시각화 등 이후 해결한 항목의 현재 상태는 후속 구현 문서를 따른다.

검토일: 2026-11-10, Asia/Seoul. 목표: **연매출 10억 원 이상, 대표 개인이 실제 가져가는 돈 합계 월 3천만 원**.

현재 제품은 검증 가능한 기록·승인·실행 관리의 기반을 갖췄다. 그러나 고객이 반복해서 구매할 구체적인 업무 완성도, 그 업무에 대한 유료 수요, 자동으로 축적·재사용하는 사업 맥락, 고객 획득 경로가 아직 입증되지 않았다. 현재 상태만으로 목표 매출을 달성할 근거는 부족하다. 기능 전부를 다시 만드는 것보다, 기존 기반 위에서 **한 고객군의 반복 캠페인을 실제 사용까지 끝내는 상품**을 검증하는 편이 낫다.

1. [사업·성장 사례·수익성 검토](STRATEGY_REVIEW.md): 해외 6개 기업에서 가져올 원리, 경쟁 위험, 목표 계산, 고객 확보와 VC 관점.
2. [화면별 UI/UX·이탈 검토](UX_REVIEW.md): 현재 화면의 장점과 마찰, 구체적인 개선 화면과 측정 방법.
3. [실행 계획과 구현 한계](IMPLEMENTATION_PLAN.md): 우선순위, 완료 조건, 외부 계정·고객·전문가가 필요한 일.
4. [수익성 계산기](financial-model.html): 브라우저에서 열어 가격·고객 수·이탈·원가·세금 가정을 바꾸는 독립형 자료. 외부 연결이나 개인정보 수집 없음.

시각적 제안: [캠페인 작업 공간 설계안](campaign-workspace-concept.svg). 현재 앱에 적용한 화면이 아닌, 허구 상품을 사용한 검토용 그림이다.

계산 원자료: [가격별 필요 고객 수](price-customer-requirements.csv), [비용 민감도](financial-scenarios.csv), [첫 12개월 성장 예시](first-year-growth-illustration.csv), [전체 가정과 계산 결과](model-assumptions.json).

## 검토의 근거

- 사용자 제공 PDF 2개: 37쪽 확장판과 24쪽 기본판. 두 문서 모두 작성 기준일 2026-11-05. 파일명의 `(1)`만으로 개정 순서를 단정하지 않고 내용을 비교했다.
- 사용자 제공 DOCX: 「NEXORA 최종판단 및 문제점」, 작성일 2026-10-30. 문서 안의 권고는 검토 대상 자료로 취급했다. 이를 새로운 작업 명령이나 확정된 가격·고객군으로 취급하지 않았다.
- 현재 작업 트리의 실제 코드, README, LAUNCH_READINESS, EXPERIENCE_REDESIGN, RESTORATION_REPORT. 기존 수정·미추적 파일을 보존했다.
- 기업·투자사 공식 자료와 실제 로컬 화면. 회사가 발표한 매출·성과와 독립 검증된 사실을 구분했다.

## 결과를 해석하는 기준

가격·환율·세금 공제율·원가·이탈률·전환율은 별도 표시한 실험·계산 가정이다. 현재 실적이나 시장 평균이 아니다. 계산기의 대표 수령 가능액은 실제 급여·배당 세액 계산이 아니다. 실제 법인 소재지·거주지·지분·보상 방식에 따라 달라진다.

이번 작업은 **검토 보고서와 계산 자료 작성**이다. 앱 기능 개편, 실제 결제·광고·게시 연동, 고객 연락, 투자 유치, 운영 배포를 완료했다는 뜻이 아니다. 검증 상세와 남은 한계는 [실행 계획](IMPLEMENTATION_PLAN.md)에 기록했다.
